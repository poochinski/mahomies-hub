# Mahomie's Hub — full audit (2026-10-10, v2.2)

How this was done: every tab and sub-page screenshotted at phone width (390px) with the real league snapshot, plus a read of the code (front end `prototype/v2.0`, server `server/`).

---

## The big picture

**What's working:** the app has real depth now: live game center, player cards, trade grader, Bench Shame, awards, records, the Book, the slot. Data is real and refreshes on its own. The look is consistent.

**The main problems, in order:**
1. **Repeated information.** The same numbers show up 2–3 times on one screen or across neighbouring screens (details per page below).
2. **Navigation is doubled.** Home "Explore" tiles, the League tile menu, and the bottom tab bar all point at the same places. "Records" is a tab *and* a tile inside League *and* a tile on Home.
3. **Long team names get cut off** in every table (Standings, Playoff odds, All-time), e.g. "To infinity and Bijar", "NabersThinkImSelli".
4. **Big gaps:** you can't see any team's **current roster**, there's **no player search**, no **league activity feed** (trades/waivers), no **schedule** (who you play next).
5. **Two identities on Me** ("Who are you?" picker and Sportsbook login) is confusing.
6. **Code housekeeping:** dead code, unused CSS, an unused React app that Railway still builds, tests that only exist in Claude's sandbox, "Banana Book" still in package.json.

## HOME

**What's there:** week line + Live/next kickoff → Your game (score, proj, playing/left, lineup check, median line) → This week (other 5 games, leader green, series tag, one upset tag) → Last week (one-line recap + High / Low / Top player tiles) → Explore (This week in history, Awards, Record book) → footer.

**Repeated / redundant**
- **Last week says everything twice.** The recap sentence ("JUICYSMOOOYAY led the week with 162.58, while Ben BornAgain brought up the rear at 69.10") is exactly the High and Low tiles below it. → Make the sentence say something the tiles don't: the blowout, the nail-biter, an upset, a record broken. Keep the tiles.
- **Explore duplicates the tab bar.** Awards and Record book are one tap away already. → Keep only "This week in history", or replace Explore with something new (see "Missing").
- **"Recap & scores →"** and the old "Weekly results" go to the same place; fine now that Weekly results is gone.

**Display**
- When the live feed hasn't loaded, the hero falls back to a giant "Week 5" with no info (the old problem). → Fallback should still say the phase from the schedule.
- Your game card is good. Median line text is long; on a 2-line wrap it's fine.

**Missing (the stuff people actually wonder about each week)**
- **Who you play next week** and their recent form (after the week ends).
- **League activity**: "Phil traded Kelce to Aaron", "Ben claimed X for $12" — nothing on Home shows trades/waivers.
- **Standings at a glance** (you removed the strip; open question where it lives — a compact "Top 6 + you" mini-table at the bottom of Home is one option).
- **Records watch**: "Someone is on pace for the highest score ever" during games.

## LEAGUE

**What's there:** 8-tile menu (Standings, Playoff odds, Awards, History, All-time, Rivals, Lab, Records), then the chosen view.

**Navigation**
- **The 8-tile menu takes ~130px on every League screen** and includes **Records**, which is already a bottom tab. → Turn it into one scrollable row of chips (like Book's Games/Props/My bets/Leaders), drop the Records tile.

**Standings page (Standings + Power rankings + "2026 weeks")**
- **Record shown twice**: Standings W-L and again under every Power rankings row ("8-0 · last 3: 139.1 ppg"). → Power rankings subtitle should only show what the table doesn't: last-3 form and the move arrow.
- **Team names cut off** in the table (team column too narrow for PF/All-play/Luck). → Avatar + short name, or let the name wrap to 2 lines, or move Luck to a tap-for-details.
- **"2026 weeks · Open season ›"** is a weak card that duplicates Home's "Recap & scores" and History's "Standings, bracket & every week". → Remove; put a week picker in History instead.
- Tapping a team opens the manager page. → Should open a **team page** with this season: roster, schedule (played + left), weekly scores chart, standings line. (Manager page = career; team page = this season.)

**Playoff odds**
- Good table, names cut off again. Hero text paragraph is long; the How-it-works button already explains it. → Trim to one line.
- Missing: "magic numbers" / what each team needs, and remaining schedule strength.

**Awards**
- Clean. **Monster Week / Bully / Heartbreaker** are season versions of Records (fine), but tapping them should open the game (some do via data-game; make all award rows open the game or week that won it).
- Missing: **Sportsbook Champion** (planned), **weekly awards** history (who won On Fire each week).

**History**
- Good season cards. "#1 seed **Un-Kirk-umcised Penix**" / "Most points **Tua Girls One Kupp**" use that season's team names, which nobody remembers. → Show current team name with "(then: …)" small.
- Each season card repeats a big "Standings, bracket & every week" button. Fine.

**All-time**
- **Table is wider than the phone**: 🔥 / 🧊 / Playoffs columns are off-screen to the right and the header shows "PLAYO". → Make it a list (one card per manager: titles, W-L, Win%, PPG, playoffs) or let people pick the column.

**Rivals**
- Rivalry card + 14×14 grid. The grid is wider than the phone (needs sideways scroll). OK as a power-user view.
- **Duplicate:** Me → "Record vs everyone" is the same data as one row of this grid.

**Lab (Bench Shame, Trade grader, Draft re-grade)**
- Best "deep" content in the app, but buried 2 taps deep under League → Lab.
- Draft re-grade shows only steals/busts. → Add **full draft board** (every pick, tappable players).

## SHEETS (pop-ups)

- **Four different "game" pop-ups**: game sheet (finished games), matchup preview, live Game Center, bye-week sheet. They overlap. → Long-term: one Game page that changes with the game's state (preview → live → final), with the preview stuff (form, series) as a section.
- **Manager page** opens from almost every name. Players now open player cards. Next: team names in a game context should open the game; in a season context, the team page.
- **Back button** only exists on the player card. → Add a simple sheet history so every pop-up opened from another pop-up has ‹ Back.

## DISPLAY / CONSISTENCY

- Truncated team names in tables (Standings, Odds, All-time, Game Center right side).
- Decimals are inconsistent: 162.58 in text vs 162.6 in tiles vs 162.60 elsewhere. → Rule: scores 2 decimals, averages 1.
- Tables wider than the phone: All-time, H2H grid.
- Lots of uppercase mono kickers on every panel; fine for style, but some screens have 3 kickers stacked.
- "How it works" buttons are on nearly every panel. Good for explaining, a bit noisy; consider a single ⓘ icon.

## CODE / BACKEND

- `prototype/v2.0/app.js` is one 216 KB file (300 functions); `app.css` 86 KB with **44 unused classes**; **4 dead functions** (`DONE`, `awardCard`, `matchCard`, `oddsBar`).
- **Unused React app** in `src/` and Vite in package.json; Railway still runs `npm run build` (wasted build time). `package.json` description still says "Banana Book".
- `/api/hub` still sends betting numbers (spread, moneyline, win %) in `lines` to every page load; only the Book should get them.
- Page load = `snapshot.json` (222 KB, stale Oct 8) inlined + `/api/hub` (similar size) → ~450 KB before anything else. Could show the snapshot only if the hub fails.
- **Tests live only in Claude's sandbox** (Book 44 checks, props 10, slot ledger). → Move them into the repo (`test/`) so any AI can run them.
- Six separate document-level click handlers; works, but new features keep adding more.
- `/api/state` and `/api/diag` unused by the app (fine as tools).
- Old builds (`prototype/v1.0`–`v1.8`, `prototype/dist`, data scripts) are archives; fine, but should stay untouched.
